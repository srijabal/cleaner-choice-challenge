One interesting thing I tried was making a bounded research loop inspired by Andrej Karpathy's autoresearch. I wanted it to test a change, save what was expected, and decide if that change helped enough. I kept it small and CPU based, using predefined settings. It did not write code or use an LLM. The loop stopped after two changes failed and kept the existing model. I think that was useful too, because running more experiments should not mean that something must be declared better. It did not find the best possible model. It only showed that these proposed changes did not qualify under the chosen rule.
